# EnergyChain Code of Conduct

## Our standard

Contributors, users and maintainers are expected to make this a welcoming, constructive technical community. Be respectful of different backgrounds and experience levels, give actionable feedback, and assume good intent while taking safety concerns seriously.

Unacceptable behavior includes harassment, threats, discriminatory remarks, personal attacks, stalking, sharing someone's private information without permission, and deliberate disruption of community discussions.

## Scope

This code applies to EnergyChain-controlled project spaces including issues, pull requests, discussions, documentation and project-related community events.

## Enforcement

Maintainers may edit or remove abusive content, request changes in conduct, temporarily restrict participation, or ban repeated or severe violations. Decisions should be proportionate to the harm and made with reasonable consideration for affected community members.

Report conduct concerns privately using the project maintainer contact method shown on the maintainer's GitHub profile. Do not disclose someone else's personal information in a public issue. Maintainers will handle reports with discretion where practical and avoid conflicts of interest.

See [GOVERNANCE.md](GOVERNANCE.md) for the current maintainer model.
