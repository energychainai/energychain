# Governance

EnergyChain is maintained by the project's founder and current maintainers rather than a formal foundation or standards organization.

## Stewardship

Kolade Atanseiye (GitHub [@Atanseiye](https://github.com/Atanseiye)) is the founding maintainer. Maintainers set the roadmap, review contributions, manage releases, and enforce security and conduct policies.

## Decisions

- Small changes are decided through reviewed pull requests.
- Significant API, licensing, safety or architectural changes should be discussed in an issue before implementation.
- Maintainers may decline contributions that undermine authorization boundaries, backward compatibility, project scope or user safety.
- Only maintainers with repository permissions can merge, tag or publish a release. PyPI releases continue to use the existing GitHub Actions Trusted Publishing workflow.

MIT licensing permits third-party forks and commercial use. That does not grant authority to use EnergyChain trademarks, represent a fork as officially maintained, or imply endorsement by the project.

Additional maintainers may be appointed as the community grows. Contributor history remains visible in Git.
