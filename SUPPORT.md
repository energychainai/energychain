# Support

EnergyChain is an early-stage open-source Python SDK. Community support is best effort and does not include production operational guarantees.

- **Installation and usage:** read [README.md](README.md), the [architecture](docs/architecture.md), and the [examples](examples/).
- **Non-sensitive bug:** open an issue using the bug report form with a minimal synthetic reproduction.
- **Enhancement or integration:** open a feature request and describe the developer use case.
- **Security issues and leaked secrets:** use [private security reporting](SECURITY.md), never a public issue.

Please provide Python version, EnergyChain version, expected and actual behavior, and relevant sanitized logs. Avoid sharing customer information, live device endpoints, access tokens, utility operational details or proprietary datasets.

Third-party providers, models, energy equipment and energy assets are not operated or supported by this repository.
